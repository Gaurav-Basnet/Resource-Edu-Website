🌐 Resource Edu Hub – Official Website

The Resource Edu Hub Website is a responsive and modern educational consultancy website built to provide students with information about abroad studies, services, blogs, and contact options.
This website represents Resource Edu Hub and is designed to be fast, user-friendly, and visually appealing.

🚀 Features

Home Page – Clean and modern hero section with mission & vision

About Us – Details about the consultancy, services, and achievements

Services Section – IELTS, PTE, JLPT, Language Prep, Visa Processing, and more

Courses Section – Clear information on available courses

Blog Section – Shows latest blogs dynamically from admin panel

Contact / Appointment Form – Students can send inquiries or book consultations

Testimonials – Student success stories & feedback

Responsive Design – Fully mobile-friendly

SEO Optimized – Fast loading, semantic HTML

🛠 Tech Stack

Laravel Blade / HTML / Tailwind CSS

JavaScript

Responsive UI/UX

Integrated with MIS backend (optional)
